# Aventura de Caza

Este proyecto, llamado **Aventura de Caza**, fue creado con la librería **PyGame** en Python. En este juego, te conviertes en un cazador y debes disparar a los pájaros que aparecen en el cielo.  
El objetivo es eliminar la mayor cantidad de pájaros posible antes de que logren golpearte.

---

# Especificaciones

- **Menú de opciones:** Incluye un menu interactivo con opciones para iniciar el juego, ver instrucciones y salir.
- **Juego de cacería:** Conviértete en un cazador, dispara balas y caza los pajaros mientras vuelan por el cielo.
- **Detección de colisiones:** El juego detecta colisiones entre las balas y los pajaros. También detecta colisiones entre los pájaros y el cazador; cuando un pájaro toca al jugador, la partida termina.
- **Pantalla de instrucciones:** Incluye un apartado donde se explican los controles básicos del juego.

---

# Controles del Juego

- **Flecha izquierda / derecha:** Mueve al cazador hacia la izquierda o derecha.
- **Barra espaciadora:** Dispara una bala desde la pistola del cazador.

---

# Instrucciones

1. Al iniciar el juego, aparecerá un menú con tres opciones:
   - **1. Inicio del juego:** Comienza la partida.
   - **2. Instrucciones:** Muestra las instrucciones del juego.
   - **X. Salir:** Cierra el juego.

2. Inicia el juego y utiliza las flechas izquierda y derecha para mover al cazador. Presiona la barra espaciadora para disparar a las presas.

3. **Objetivo:** Caza la mayor cantidad de presas posible antes de que te golpeen.

---

# Requisitos del Sistema

- Python 3.x
- PyGame 2.0 o superior

---

# Instalación

1. Descarga los archivos del proyecto en tu máquina local.

2. Asegúrate de tener Python 3.x y PyGame instalados. Puedes instalar PyGame con el siguiente comando:

```bash
py -m pip install pygame
```

3. Navega al directorio donde está ubicado el archivo `Test.py` y ejecuta el juego:

```bash
py Test.py
```
